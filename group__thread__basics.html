Detailed Description

basic functions and classes to allow multi-threading

These functions and classes mostly provide a thin wrapper around the POSIX threads API. While they can be used as-is to develop multi-threaded applications, in practice the Thread-safe image looping and Thread-safe queue APIs provide much more convenient and powerful ways of developing robust and efficient applications.
