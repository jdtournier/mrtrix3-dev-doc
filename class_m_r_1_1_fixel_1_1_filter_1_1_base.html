Detailed Description

A base class for defining fixel data filters.

The Fixel::Filter::Base class defines the basic interface for defining filters that operate upon fixel data. It allows these filters to be initialised, set up and run using base class pointers, and defines a standardised functor interface that fixel data filter classes should ideally conform to.
