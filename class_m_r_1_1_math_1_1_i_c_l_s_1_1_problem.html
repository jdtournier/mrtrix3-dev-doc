set up constrained least-squares problem

the problem is to solve norm(Hx - b) subject to Ax >= 0. This sets up a class to be re-used and shared across threads, assuming the matrices H & A don't change, but the vector b does.

  • problem_matrix: H
  • constraint_matrix: A
  • solution_min_norm_regularisation: an additional minimum norm constraint that will be added to the problem cost function, to stablise ill-posed problems.
  • solution_min_norm_regularisation: used to stabilise the estimation of the Lagrangian multipliers to handle cases where they become degenerate (otherwise leads to errors in the Cholesky decomposition). Default is zero, set it to a small value such as 1e-10 to help with these kinds of problem.
  • max_iterations: the maximum number of iterations to run. If zero (default), this number is set to 10x the size of x.
