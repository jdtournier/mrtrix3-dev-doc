Detailed Description

a filter to perform an FFT on an image

Typical usage:

auto input = Image<complex_value_type>::open(argument[0]);
Filter::FFT fft (input);
auto output = Image::create<complex_value_type> (fft, argument[1]);
fft (input, output);
