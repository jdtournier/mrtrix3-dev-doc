computes C = alpha A B + beta C or C = alpha B A + beta C, where A is symmetric

Computes the symmetric matrix-matrix product C = alpha A B + beta C or C = alpha B A + beta C, where the matrix A is symmetric.

Parameters
Cthe target matrix
sidedetermines the order of the product:
  • CblasLeft: C = alpha*A*B + beta*C
  • CblasRight: C = alpha*B*A + beta*C
betaused to add a multiple of C to the final product
alphaused to scale the product
uplodetermines which part of A will be used:
  • CblasUpper: upper triangle and diagonal of A
  • CblasLower: lower triangle and diagonal of A
Aa Matrix
Ba Matrix
Returns
