std::string MR::ProgressInfo::ellipsis

the ellipsis (three dots) to show at the end of the text (if applicable)

If the progress is initialised based on a text string and then updated, an ellipsis is shown at the end of the message until the progress is completed. If the text is updated using a functor, then no ellipsis is shown.
