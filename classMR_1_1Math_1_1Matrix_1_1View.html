Detailed Description

template<typename ValueType>
class MR::Math::Matrix< ValueType >::View

A class to reference existing Matrix data.

This class is used purely to access and modify the elements of existing Matrices. It cannot perform allocation/deallocation or resizing operations. It is designed to be returned by members functions of the Matrix classes to allow convenient access to specific portions of the data (i.e. a subset of a Matrix).
